Compilación segura y ofuscación oficial para tus recursos

Características

  • Compilación real via luac.mtasa.com
  • Soporte para Carpetas completas o ZIP
  • Selección flexible de archivos
  • Actualización automática de meta.xml

Cómo usar

  1. Sube un .zip o selecciona una carpeta.
  2. El sistema detectará automáticamente los archivos .lua.
  3. Marca los archivos que deseas compilar/ofuscar.
  4. Haz clic en "COMPILAR Y DESCARGAR".
  5. Sube el ZIP resultante a tu servidor MTA.
